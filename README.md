# rust-ferris-readings
Ferris the crab does some readings.

# Releases

## Version 1
This is a basic script which reads the file `rhyme.txt` and Ferris the crab will read each line.

In the folder, run the command `./rust-ferris-readings` in the terminal. You should see something like this:

````
 ____________________________
 _____________________________
< This is an example line of text >
 -----------------------------
        \
         \
            _~^~^~_
        \) /  o o  \ (/
          '_   -   _'
          / '-----' \
````
